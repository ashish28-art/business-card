# Digital Business Card

A single-page digital business card built with HTML and CSS — a Scrimba solo project.

## Overview

A learning project completed as part of Scrimba's frontend developer path: a static profile card with an avatar, name, role, and location, laid out and styled with plain CSS. Card content (name and photo) comes from the Scrimba course materials by Per Harald Borgen.

## Tech Stack

- HTML
- CSS

## Project Structure

```
business-card/
├── game2.html    # Card markup
├── game2.css     # Card layout and styling
└── per.png       # Avatar image (course material)
```

## Getting Started

Open `game2.html` in any browser. No build step or dependencies.
